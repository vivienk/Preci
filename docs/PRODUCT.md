# Product

Preci is a relationship-memory assistant that helps people remember small signals about people they care about and turn those signals into thoughtful gifts at the right time.

## Core loop
Person → relationship memories → occasion → 3 explainable recommendations → save gift → plan/remind → feedback.

## Memory types
- Mentioned
- Liked
- Needed
- Avoid

## Product principles
- Feel like a relationship-memory system, not a generic gift-search chatbot.
- Recommendations should explain why they fit using stored signals.
- Favor a small, reliable MVP over broad feature scope.
- Keep privacy and user control visible around personal relationship data.

## MVP
- Create/manage people.
- Add structured memories.
- Add/select an occasion and budget.
- Generate exactly three explainable gift ideas.
- Save a gift and basic planning state.
- Gate premium value through RevenueCat.

## Out of scope for MVP
Marketplace, checkout, broad contacts/calendar sync, social graph, collaboration, and unrelated lifestyle features unless explicitly reprioritized.
