# Shipaton

Preci is being built for RevenueCat Shipaton 2026.

## Shipping goal
Deliver a real native mobile app that can be publicly released to the App Store, not merely a web prototype.

## Priority
1. Stable native app.
2. Core relationship-memory loop works end to end.
3. RevenueCat purchase + entitlement path works.
4. App Store release readiness.
5. Submission assets and polish.

## Scope control
Do not add marketplace, checkout, broad contacts/calendar sync, collaboration, or unrelated social features before the core path is reliable.

## Verification checklist
- App installs and launches in a native build.
- Core navigation works.
- People/memories/occasions persist.
- Recommendation flow returns three explainable results.
- Saved gift flow works.
- RevenueCat purchase and restore are verified.
- Premium entitlement survives relaunch correctly.
- App Store metadata/privacy requirements are reviewed.
- Current Shipaton eligibility/deadline rules are rechecked from the official source before submission.
